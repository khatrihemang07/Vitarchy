# Taste
- Keeps backend in Rust for speed and efficiency. Confidence: 0.9
- Requires local-only app: loads zero external resources at runtime, binds loopback, no Artifacts/publishing. Confidence: 0.95
- Expects modular, scalable, maintainable code: well-arranged explainable structure, single source of truth, low redundancy, helpful logging for debugging, clear concise comments. Confidence: 0.95
- Wants implementation via Sonnet subagent with thorough verification and testing, including viewing frontend in ego-browser. Confidence: 0.9
- Wants high-quality consistent UI/UX that is unique/vibrant, responsive, with very subtle motion over flashy count-up/scale animations. Confidence: 0.85
- Prefers parallel live and stage environments: test and verify on stage only, leave live data and running servers untouched. Confidence: 0.85
- Prefers tunable behavior exposed as a single easily-changed variable/value rather than hardcoded logic or extra UI. Confidence: 0.75
- Prefers interactive clarification with ask-user tool / grill-with-docs for open product decisions before implementing. Confidence: 0.8
